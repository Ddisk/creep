01　荷重の出発点

アンバランス荷重は、重心のずれから生まれる

中心軸 → 重心ずれ → 回転 → 荷重

中心軸から e だけずれた重心が回転し、ラジアル方向の荷重が発生する。

矢印は回転中のある瞬間。荷重方向も回転する。

一般的な遠心力 → モーターのアンバランス

F = mrω²　→　F = meω²

m：質量 [kg]　r：回転中心からの距離 [m]
e：重心の偏心量 [m]　ω：角速度 [rad/s]

釣り合い等級から荷重へ

G = eω　→　e = Gω
F = m × Gω × ω² = mGω
ω = 2πN60

N：回転速度 [min⁻¹]

単位をそろえる

Gの表示単位は [mm/s]。F = mGω の計算ではGを [m/s]に換算する。
釣り合い等級から求める荷重は、指定回転速度でその等級に相当する残留不釣り合いを想定した値。

02　円環モデル

客先負荷の質量が未知なら、イナーシャから逆算

D・d・Lは [m]、密度ρは [kg/m³]。
均一な材質・肉厚の円環を仮定する。

① 中実円板から、軸穴部分を引く

J₁ = 12M₁R₁²　 M₁ = πR₁²Lρ　 R₁ = D2
J₁ = πLρD⁴32　 J₂ = πLρd⁴32
JL = J₁ − J₂ = πLρ(D⁴ − d⁴)32

② 既知のイナーシャから外径を逆算

D = { 32JLπLρ + d⁴ }¼

③ 質量 → アンバランス荷重

MC = πLρ(D² − d²)4
F₁ = MCGω

負荷イナーシャ JL [kg·m²] → 外径 D
→ 質量 MC [kg] → 荷重 F₁ [N]

04　F₁〜F₆の整理

荷重の求め方を、部品ごとに使い分ける

F₁｜客先負荷

F₁ = MCGω

円環モデルで逆算した質量と釣り合い等級から求める。

F₂・F₄｜ローター

U = mr　 F₂ = Uω²
F₄ = F₂

U [kg·m] は各面の既知値。今回は両側で同じ値。

F₃｜磁気アンバランス

F₃ = 既知値

指定されたラジアル荷重を、そのまま使用する。

F₅｜ブレーキ

F₅ = MBGω

MB [kg] は既知。客先負荷と同じGを仮定する。

F₆｜エンコーダ

F₆ = 0

今回は荷重を無視するため、l₆の数値は計算に不要。

計算モデルの前提

全外力を同じ方向にそろえた瞬間を計算。実際は位相や方向に応じて成分ごとに合成する。

自重・伝達荷重・共振による増幅は含めない。

05　釣り合いから軸受荷重を求める

客先負荷は、L側軸受を挟んで逆のモーメント

① モーメントの釣り合い｜L側基準

FNLl₇ = F₂l₂ + F₃l₃ + F₄l₄
+ F₅l₅ + F₆l₆ − F₁l₁

F₆ = 0、F₄ = F₂ を代入すると、

FNL = F₂l₂ + F₃l₃ + F₂l₄ + F₅l₅ − F₁l₁l₇

② ラジアル方向の力の釣り合い

FL + FNL = F₁ + F₂ + F₃ + F₄ + F₅
FL = F₁ + F₂ + F₃ + F₄ + F₅ − FNL

まずモーメントから FNL を求め、
力の釣り合いから FL を求める。

緑の矢印は軸受が軸に及ぼす反力。軸受が受ける荷重は逆向き・同じ大きさ。負の結果は仮定と逆向き。
距離をすべてmmにそろえれば、モーメントはN·mmで計算できる。

06　クリープとの関係

ラジアル荷重が、はめあい面の相対すべりにつながる

アンバランス荷重→FL・FNL→軸受輪のラジアル荷重→はめあい面

内輪と軸、または外輪とハウジングの間で起こる。転動体の転がりとは別の現象。

クリープとは

軸受輪と軸またはハウジングのはめあい面で、軸受輪が円周方向に徐々に移動する現象。

荷重があるだけでは、発生は決まらない

はめあい・有効しめしろ、荷重の大きさと方向、材質・剛性、温度差による膨張などが関係する。

条件によって相対すべり → クリープ

「回転荷重」は、軸受輪から見て考える

軸受輪に対して荷重方向が移動するかを確認する。軸と一緒に回るアンバランス荷重は、静止した外輪に対して回転荷重となる。

ここで求めるのはクリープ検討の入力となる荷重。発生判定や必要しめしろの計算は別途行う。
参考：NSK「Fits and Internal Clearance」

08　数値計算②

例題：負荷側 17.49 N、反負荷側 6.68 N

① NL側軸受荷重｜L側まわりのモーメント

FNL = 8.225×15.65 + 6.37×24.65 + 8.225×33.65 + 0.152×50.5 − 1.192×42.577.8 ≈ 6.68 N

② L側軸受荷重｜ラジアル方向の力の釣り合い

FL = 1.192 + 8.225 + 6.37 + 8.225 + 0.152 − 6.68 ≈ 17.49 N
負荷側軸受FL ≈ 17.49 N
反負荷側軸受FNL ≈ 6.68 N
釣り合いの確認合計 ≈ 24.16 N

外力の合計と一致

途中の数値は表示用に丸めている。結果は丸め前の値で算出。図は縮尺不同。
この荷重と、はめあい・回転荷重・材質・温度などを合わせてクリープを検討する。
