FB：ブレーキ、FR：ローター、FM：磁気、FC：客先イナーシャのアンバランス荷重。

3. アンバランス荷重

F = m × e × ω²
ω = 2πn / 60

m：質量、e：偏心量、n：回転速度[rpm]。

ブレーキ、ローター、客先イナーシャは質量アンバランスとして整理できる。磁気アンバランス荷重は別系統の外力として扱う。

4. 客先イナーシャの外径と質量

客先イナーシャは長さ 0.02 m、軸端径を内径とする円環として扱う。

ri = d / 2
JL = 1/2 × ρ × π × L × (ro4 - ri4)
ro = { 2JL / (ρπL) + ri4 }1/4
mC = ρπL(ro2 - ri2)

5. ローター質量の簡易推定

JM = 1/2 × mR × rR2
mR = 2JM / rR2
モーターイナーシャがローター単体の慣性モーメントとして扱える場合の簡易モデル。総慣性値ならローター質量そのものにはならない。

6. 力の釣り合い

RNL + RL = FB + FR + FM + FC

7. モーメントの釣り合い

RLLB = FBxB + FRxR + FMxM + FCxC
RL = (FBxB + FRxR + FMxM + FCxC) / LB
RNL = FB + FR + FM + FC - RL
客先イナーシャがL側軸受より外側にある場合はオーバーハング荷重となる。

8. クリープとの関係

各部のアンバランス荷重 → L/NL軸受反力 → 軸受輪に作用するラジアル荷重 → はめあい条件が不十分 → 相対すべり → クリープ

クリープ（Bearing Creep）は、軸受輪と軸またはハウジングのはめあい面で、軸受輪が円周方向に少しずつ移動する現象。

アンバランス荷重があるから必ずクリープが発生するわけではない。荷重、回転荷重かどうか、はめあい、材質、温度などを合わせて評価する。

10. 全体の流れ

既知仕様 → 各部の質量・形状 → アンバランス荷重 → 作用位置 → 力の釣り合い → モーメントの釣り合い → L/NL軸受反力 → クリープ検討
学習・説明用の簡易モデル。実設計では対象モーター、軸受、はめあい、支持条件、メーカー基準に従って評価する。
