クリープ

アンバランス荷重からL側・NL側軸受荷重を求め、クリープとの関係を整理する。

1. アンバランス荷重とは

質量 m の物体が回転中心から距離 r の位置を角速度 ω で回ると、遠心力が発生する。

F = m r ω²

モーターでは、回転体の重心が回転中心軸から e だけずれていると、その重心が軸のまわりを回転する。

F = m e ω²

この回転するラジアル方向の力を、ここではアンバランス荷重として扱う。

今回の前提
スラスト荷重は考えず、すべて軸に対して直角なラジアル方向の荷重として扱う。

2. 釣り合い等級との関係

G = e ω
e = G / ω

これを F = meω² に代入すると、

F = m G ω
ω = 2πN / 60

質量・釣り合い等級・回転速度が分かればアンバランス荷重を求められる。

3. 客先負荷質量が未知の場合

客先負荷を、長さ L、外径 D、内径 d、密度 ρ の円環として考える。

J₁ = 1/2 M₁ R₁²
M₁ = πR₁²Lρ

R₁ = D/2 より、

J₁ = πLρD⁴ / 32

同様に内径 d のくり抜き部分は、

J₂ = πLρd⁴ / 32
JL = J₁ - J₂ = πLρ(D⁴ - d⁴) / 32

Dについて解くと、

D = { 32JL / (πLρ) + d⁴ }1/4

客先負荷質量は、

MC = πLρ(D² - d²) / 4

したがって、客先アンバランス荷重は、

F₁ = MC G ω

5. 各アンバランス荷重

客先負荷：F₁

F₁ = MC G ω

ローター：F₂、F₄

ローターの不釣り合い量を U = 3 g·cm とする。

U = mr
F = Uω²

今回は負荷側と反負荷側を同じとする。

F₂ = F₄ = Uω²

磁気アンバランス：F₃

F₃ = 6.37 N（既知）

ブレーキ：F₅

F₅ = MB G ω

エンコーダ：F₆

F₆ = 0

6. L側軸受まわりのモーメントの釣り合い

すべての距離は負荷側軸受中心から測る。

FNLl₇ = F₂l₂ + F₃l₃ + F₄l₄ + F₅l₅ + F₆l₆ - F₁l₁

今回は F₆ = 0、F₄ = F₂ なので、

FNL = { F₂l₂ + F₃l₃ + F₂l₄ + F₅l₅ - F₁l₁ } / l₇

7. 力の釣り合い

FL + FNL = F₁ + F₂ + F₃ + F₄ + F₅
FL = F₁ + F₂ + F₃ + F₄ + F₅ - FNL

10. クリープとの関係

アンバランス荷重 → 軸受荷重 FL・FNL → 軸受輪にラジアル荷重 → はめあい条件が不十分 → はめあい面で相対すべり → クリープ

クリープ（Bearing Creep）とは、軸受輪と軸またはハウジングのはめあい面で、軸受輪が円周方向に少しずつ移動する現象。

アンバランス荷重があるから必ずクリープが発生するわけではない。実際には、荷重の大きさ、回転荷重かどうか、はめあい、材質、温度などを合わせて評価する。
学習・説明用の簡易モデル。実設計では対象モーター、軸受、はめあい、支持条件、メーカー基準に従って評価する。
